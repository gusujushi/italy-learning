# 意大利语能力岛 · 90 天课程设计

> 从零开始，90 天、9 座岛、听说读写五项能力同步推进。
> 本文是课程的"总设计图"：先讲设计思路，再给出 90 天逐日大纲，最后说明评估与质检方式。

---

## 1. 设计思路：对齐「新概念英语能力岛」

"能力岛"指的是 GitHub 仓库 [gusujushi/nce-english-island](https://github.com/gusujushi/nce-english-island)（新概念英语能力岛 1–4 册）：把新概念英语的原声和课文变成**闯关式学习**——全程英式发音、彩色句子分析、每课 6 步学习法、学习计划可调（默认 30 天学完四册，可改 60 / 90 / 120 天）。

意大利语版沿用这套**程序流程**，内容则是 90 天的原创课程。逐项对应、没有移植的部分和原因见 [REFERENCE_ALIGNMENT.md](REFERENCE_ALIGNMENT.md)。提炼出的核心设计：

| 能力岛的做法 | 本课程的对应设计 |
| --- | --- |
| 每课 6 步：导读盲听 → 词汇 → 逐句精读 → 语法透视 → 影子跟读 → 闯关测验 | 同样 6 步，一课 ≈ 45–60 分钟；60 分过关，记录最好成绩 |
| 彩色句子分析 | 谓语 / 连词 / 非谓语 / 介词 / 代词着色 + 意群 + 主干 + 动词变位说明 + 语法点；针对意大利语写了形态库和消歧规则 |
| 学习计划可调，每 5 天一轮（4 天新课 + 1 天复习） | 默认 90 天；预设 30 / 60 / 90 / 120 天或自定义；按课的分量分配，自由日，落后提示，不锁课 |
| 生词本 + 间隔复习 | 莱特纳盒子；☆ 收藏词 / 句子，学完一课自动入库 |
| 影子跟读（录音 / 意群 / 自动） | 同样三种方式 |
| 全程原声 | 全程自带音频（合成语音；没有可直接复用的意大利语"新概念式"原声教材） |
| AI 老师 | 可选的 DeepSeek 逐句讲解 |

和新概念英语不同的地方：

1. **发音前置。** 意大利语拼写几乎"所见即所读"，第 1–10 天集中打通发音体系，之后每天仍有"发音小练习"（`pron`）持续巩固。
2. **口语前置。** 英语新概念从语法出发；这里以"能马上用"的生活场景（咖啡吧、餐厅、问路、酒店）驱动，语法只讲当天要用的那一点。
3. **语法分析针对意大利语。** 难点不在词序，而在动词变位（携带人称、时态）、主语省略、代词粘在动词上、冠词与代词同形——所以彩色分析以"谓语 + 变位说明"为中心。
4. **内容原创。** 没有可以直接使用的教材，课文、词汇、讲解、题目全部原创，并用脚本自动生成练习。

  ├ 第5岛 社交岛   Isola degli Amici          Day 41–50

  ├ 第7岛 记忆岛   Isola dei Ricordi          Day 61–70

**每座岛的第 10 天是"岛屿关卡"**（综合复习 + 测试，通关得岛屿徽章）；第 30、60、90 天是阶段毕业考。

**能力侧重**随阶段移动：

| 阶段 | 听 | 说 | 读 | 写 | 说明 |
| --- | :-: | :-: | :-: | :-: | --- |
| 一 | ★★★ | ★★★ | ★★ | ★ | 以听说为主；写作限于词、短句、听写、填空 |
| 二 | ★★★ | ★★★ | ★★★ | ★★ | 加入 80–100 词短文阅读；写 40–60 词的小短文 |
| 三 | ★★★ | ★★★ | ★★★ | ★★★ | 阅读通知/邮件/短故事；写 100–150 词；长段口语 |

## 3. 每课学习流程：6 步学习法（约 50–60 分钟）

沿用"能力岛"的 6 步结构，以**课文为中心**，每一步都有明确的能力目标。课程页顶部是步骤条，可以随时跳到任一步；每一步做完会打勾，6 步全部完成才算"学完一课"。

| 步骤 | 时长 | 做什么 | 主训练的能力 |
| --- | --- | --- | --- |
| 🎧 ① 导读盲听 | 8′ | 看场景、目标和"听前问题"；**盲听**整段对话（可慢速，可多遍），再做 2–3 道理解题；可选显示文本 | 听 |
| 🔤 ② 意语词汇 | 8′ | 词卡（拼写、重读音节、中文、课文例句）；遮住中文自测；☆ 加入生词本；配对 / 选择 / 听音选义小练习 | 读 · 记 |
| 🔍 ③ 逐句精读 | 15′ | 点一句听发音，看**彩色句子分析**、意群、主干、动词变位说明、语法点；点词看释义；单句 / 整段循环、变速、中 / 意显隐；带短文的课，精读后有阅读理解题 | 读 · 知识 |
| 🧩 ④ 语法透视 | 12′ | 本课语法讲解、从本课句子里扫描出的语法点（附课文例句）、动词一览表、发音小练习、文化提示、**微写作**（用本课句型写几句话，附示范答案和自查清单）、知识小测 | 知识 · 写 |
| 🗣️ ⑤ 影子跟读 | 12′ | 逐句录音对比 / 意群高亮跟读 / 自动连读 / 角色扮演（你演其中一个角色）；另有每课 3–5 个「看中文，开口说」场景任务 | 说 |
| 🏆 ⑥ 闯关测验 | 8′ | 10 题自动生成的综合测验（听选、听写、填空、排序、翻译、知识）；≥ 60 分过关；本课词汇和关键句自动加入生词本 | 综合 |

写作训练分散在几处：词汇和语法步骤里的小练习、闯关测验里的听写 / 排序 / 键入填空 / 翻译，以及语法步骤里每课一个的**微写作**。

**课前热身（约 5′，可选）**：首页会提示"有 N 张生词卡到期"，先清掉再学新课效果更好。

**成绩规则**：测验正确率 ≥ 60% 过关（这一步打勾）；≥ 80% ★★；≥ 95% ★★★。**没有锁**——任何一课都可以随时进入；想提高成绩可以重测，系统记录历史最好成绩。

### 学习计划

- **每 5 天一轮**：前 4 天学新课，第 5 天是**复习日**（回顾这一轮学过的课，做一套综合测验，≥ 60 分通关）。
- **按分量分配**：每课有"分量"（词汇数、对话和短文字数、语法块、题目数的加权和），按分量把课分配到各学习日——轻的课合并到同一天，重的课独占一天。权重在每个阶段内部归一化，所以默认 90 天计划里第 1–30 课恰好在前 30 天。
- **可调**：预设 30 / 60 / 90 / 120 天或自定义 5–365 天；可改起始日期；可选只学其中几座大岛。计划比课多时多出来的日子是**自由日**；天数不是 5 的倍数时最后一天固定为总复习。
- **今天是第几天**按日历从起始日期算；落后时首页提示落后几课，进度不会丢。

## 4. 听说读写如何练

### 听 Ascolto
- 导读盲听 → 理解题 → 逐句精读时带文本精听（先听懂大意，再抠细节）。
- 听音选义、听写词/句、听力是非题。
- 阶段三加入"真实语速"的通知、语音留言、新闻简报（第 87 天）。

### 说 Parlato
- **影子跟读**：每句"听一句—说一句—录一句—回放比较"；或按意群逐块高亮跟读、自动连读。
- **角色扮演**：程序读 A 的台词，你说 B 的台词（可换角色）。
- **看中文说意大利语**：每天 2–4 条场景任务。
- **补救策略**（第 88 天）：没听懂怎么办——"Può ripetere, per favore?""Come si dice … in italiano?"

### 读 Lettura
- 对话本身就是阅读材料；阶段二、三的大多数日子另附一篇 60–100 词的短文和阅读理解题（全程共 53 篇）。
- 第 36 天租房广告、第 67 天通知与新闻、第 85 天《木偶奇遇记》开篇（公有领域）。
- 精读页点击任意词看释义和变位说明（释义来自到本课为止学过的词汇表）。

### 写 Scrittura
- 阶段一：听写 → 填空 → 句子排序 → 中译意 → 一句话写作。
- 阶段二：便条、明信片、短信、日记（第 54、59 天）。
- 阶段三：正式邮件、故事复述、短文（第 68、69、86 天）。
- 每个写作任务都附**示范答案**与自查清单。

## 5. 发音训练体系

| 天数 | 重点 |
| --- | --- |
| 1 | 5 个纯元音；不要弱化、不要拖尾 |
| 2 | 不送气的 p/t/c（≈ 汉语拼音 b/d/g）与浊音 b/d/g；字母表；拼读名字 |
| 3 | c/g 的软硬（ce ci / ca co cu / che chi）；不发音的 h；sc |
| 4 | gn、gli、z、qu；**双辅音**（pala/palla）；大舌音 r |
| 5 | 重音规则（倒数第二音节）、重音符号、疑问语调 |
| 6–10 | 数字、国名、冠词连读、咖啡吧词汇的综合应用；绕口令 |
| 11 起 | 每天一个"发音小练习"：与当天词汇结合（双辅音、z、gli、重音例外…） |

发音实验室（App 内）包含：字母与发音对照表、最小对立词听辨（caro/carro）、重音练习、绕口令（scioglilingua）。

## 7. 复习与评估

- **生词本（间隔复习）**：莱特纳盒子法，6 个盒子，间隔 1 / 2 / 4 / 8 / 16 / 32 天。四档自评：不会（回到第 1 盒，今天再来一次）、模糊（留在原盒，间隔减半）、记得（升一盒）、很熟（升两盒）。每个词、每句关键对话是一张卡；同一个词在多课出现，只建一张卡（在它第一次出现的那一课加入）。学完一课自动入库（可在设置里关闭），也可以随时 ☆ 收藏词或课文句子。另有"错题重练""收藏复习"和"随机巩固"。
- **闯关测验**：每课 10 题，混合听选、听写、填空、排序、翻译。
- **岛屿关卡**：每个小岛的第 10 课，题量 20，覆盖本岛全部内容。
- **阶段毕业考**：第 30 / 60 / 90 课，30 题，覆盖整个阶段的内容。
- **复习日综合测验**：每 5 天一次，覆盖这一轮学过的课（16–30 题），≥ 60 分通关。
- **五项能力雷达**：听、说、读、写、知识，各按近期 40 题的正确率滚动计算，直观看到短板。口语只能"自评"——程序不会替你判断发音对不对。

## 8. 预期水平（实话实说）

按每天 50–60 分钟、认真完成所有步骤计：

- 第 30 天：能发音正确地读出意大利语单词；能在咖啡吧、餐厅、车站、酒店完成基本对话（大致相当于 A1 入门）。
- 第 60 天：A1 的语法和主题基本完整，能叙述简单的过去与计划。
- 第 90 天：约 A2 水平，含少量 B1 入门内容（条件式、虚拟式入门）。**这不等于 90 天后能流利交谈**；之后建议用真实材料大量输入，并找人对话。第 90 天提供后续路线（CELI / CILS / PLIDA）。

## 9. 内容原则与质检

1. **原创内容**：参考项目大多无开源许可证，因此课文、词汇释义、讲解均为原创，只借鉴设计思路。
2. **拼写质检**：全部意大利语文本用 LibreOffice 意大利语 Hunspell 词典逐词检查；未登录词人工复核（专有名词除外）。
3. **难度校验**：以 OpenSubtitles 词频表检查词汇覆盖，避免前期出现生僻词。
4. **结构校验**：脚本检查天数连续、对话格式、答案序号、必填字段。
5. **音频**：使用 Piper 的 `it_IT-paola-medium`（训练数据 CC0）合成；同时保留浏览器语音合成作为回退。合成语音不等于真人发音，**重音和语调请多听真人材料校正**。质检做过：重音位置与课程标注逐词核对（525 个词，一致率 99.4%，不一致的 2 个是课程标注错误，已更正）、双辅音时长对比、句子级语音识别回听抽查、响度与峰值检查。
