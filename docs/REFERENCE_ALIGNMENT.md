# 与「新概念英语能力岛」的对齐说明

本项目的程序流程对齐的是 GitHub 仓库 **[gusujushi/nce-english-island](https://github.com/gusujushi/nce-english-island)**（新概念英语能力岛 1–4 册）。
它的自我介绍是：

> 一个在电脑浏览器里运行的英语学习程序。它把你下载的新概念英语第一至第四册（原声 MP3 + 课文）变成闯关式学习：全程英式发音 · 彩色句子分析 · 每课 6 步学习法 · 学习计划可调（默认 30 天学完四册，也能改成 60 / 90 / 120 天）。

意大利语版把这四点逐项做了对应，并保留了本项目已有的 90 天原创课程内容。这份文档记录：**对齐了什么、改造了什么、没有移植什么，以及为什么。**

> 关于来源：只通读了参考仓库的 README、页面结构、数据格式、`app.js` / `grammar.js` 的逻辑和 PWA 配置，用来理解**产品流程和设计取舍**；本项目的代码（计划引擎、形态库、着色规则、界面）全部独立重写，没有复制参考仓库的代码或文字。参考仓库里没有 LICENSE 文件，这也是不复制的原因之一。

## 一、四大特色的对应

| 参考项目 | 意大利语版 | 说明 |
| --- | --- | --- |
| **全程英式发音**（新概念原声 MP3；没有时用 Edge 的英式语音） | **全程意大利语发音**：`audio/` 里预生成的 3,324 条 MP3（课文、词汇、语法例句、练习用句），没有对应文件时回退到浏览器的意大利语语音 | 意大利语没有"新概念"那样可直接用的原声教材，所以用开源语音模型合成（Piper `it_IT-paola-medium`，训练数据 CC0）。**这是合成语音，不是真人**——见下文"诚实说明" |
| **彩色句子分析** | **意大利语版彩色分析**：连词 / 疑问词紫、**谓语红**、非谓语（不定式 / 分词 / 副动词）绿色波浪线、介词蓝、代词橙、本课词汇黄底；另有意群切分、主干提示、动词原形与变位说明（含"主语省略"提示）、44 个意大利语语法点、难度星级 | 意大利语的难点和英语不同：动词变位携带人称、主语常省略、代词粘在动词上（dimmi、mangiarlo）、冠词与代词同形（lo / la / li / le）。所以不是照搬英语规则，而是写了一套意大利语形态库 `js/morph.js`（规则变位 + 不规则动词 + 派生动词 + 接代词）和上下文消歧规则 `js/grammar.js` |
| **每课 6 步学习法** | **每课 6 步**，步骤名称和顺序相同：🎧 导读盲听 → 🔤 意语词汇 → 🔍 逐句精读 → 🧩 语法透视 → 🗣️ 影子跟读 → 🏆 闯关测验（≥60 分过关） | 见下表"6 步的具体对应" |
| **学习计划可调**（默认 30 天四册；30 / 60 / 90 / 120） | **默认 90 天学完 90 课**；预设 30 / 60 / 90 / 120 天，也可自定义 5–365 天；可改起始日期、可选只学其中几座大岛 | 默认值不同：参考项目是"一个月学完四册"，本项目的目标是"90 天从零开始，前 30 天掌握发音和日常 / 差旅口语"，所以默认 90 天，前 30 课正好落在前 30 天内 |

### 6 步的具体对应

| 步骤 | 参考项目 | 意大利语版 |
| --- | --- | --- |
| ① 导读盲听 | 读导读，盲听整课音频 | 场景 / 目标 / 听前问题 + 整段对话盲听（可慢速）+ 可选显示文本 + 听力理解题 |
| ② 词汇 | 英音词汇 | 词卡（拼写、**大写标出重读音节**、中文、**课文里的例句**并高亮该词）、遮住中文自测、☆ 加入生词本、词汇小练习（配对 / 选择 / 听音选义）。*不做 IPA，见下文* |
| ③ 逐句精读 | 点一句，看彩色分析 | 左侧句子列表（点读、变速、单句 / 整段循环、中 / 意显隐），右侧（手机上是底部面板）彩色分析、意群、主干、动词、语法点、点词看释义、收藏句子、AI 老师（可选）；带短文的课，精读后有阅读理解题 |
| ④ 语法透视 | 本课语法现象汇总 | 本课语法讲解 +**从本课句子里自动扫描出的语法点**（每个点配课文里的真实例句，可跳到精读看颜色）+ 动词一览表（按原形归类）+ 发音小练习 + 文化提示 + **微写作**（沿用本项目第一版的写作任务）+ 知识小测 |
| ⑤ 影子跟读 | 录音 / 意群 / 自动三种方式 | 同样三种：🎤 逐句录音（听 → 录 → 对比 → 自评，浏览器支持时可用语音识别）、🧩 意群跟读（按播放进度逐块高亮）、▶ 自动连读（放一句、留出同样长的空档让你跟读）；**多出**🎭 角色扮演和每课 3–5 个「看中文，开口说」任务（沿用本项目第一版的口语训练） |
| ⑥ 闯关测验 | 过关线 60 分 | 同样 60 分过关；10 题（岛屿关卡 20 题、阶段毕业考 30 题），题目由本课内容自动生成，每次不同；记录历史最好成绩与星级 |

## 二、计划引擎的对应

| 机制 | 参考项目 | 意大利语版 |
| --- | --- | --- |
| 每 5 天一轮 | 4 天学新课 + 1 天复习 | 相同 |
| 按"分量"分配课程 | 每课有权重（内容量），按累计权重比例分配到学习日 | 相同思路：权重 = 词汇、对话字数、短文字数、语法块、题目的加权和。**不同点：权重在每个阶段内部各自归一化**，这样默认 90 天计划里第 1–30 课正好在第 1–30 天内，不会因为某一课内容多而把阶段边界挤歪 |
| 课比天少 / 天比课多 | 多出来的日子是"自由日" | 相同；另外，天数不是 5 的倍数时，**最后一天固定为总复习** |
| 复习日 | 做一套综合测验，≥60 分通关 | 相同：覆盖这一轮学过的课，题量随课数变化（16–30 题） |
| 今天是计划第几天 | 按日历从起始日期算 | 相同；起始日期在未来 / 计划已结束 / 落后几课都有提示 |
| 强度提示 | 每天平均 > 150 分钟时提醒 | 每个学习日平均 > 120 分钟时提醒（本课程每课按 ~1.4 分钟 / 分量单位估算，约 45–55 分钟一课） |
| 不锁课 | 任何一课都能进 | 相同——**去掉了旧版的"通关才解锁下一天"** |

计划引擎是纯函数（`js/plan.js`），有 11 项单元测试。

## 四、没有移植的部分（以及原因）

| 参考项目的功能 | 为什么没有移植 |
| --- | --- |
| **导入自己的 MP3 / 课文、LRC 解析、"我的课文文件"、在线下载录音和课文** | 这是参考项目的核心流水线（把你**已有的**新概念原声和课文导入程序）。本项目的课文、音频都是**内置的原创内容**，不需要导入；也没有可以合法下载的"意大利语新概念"原声教材，所以不做下载功能 |
| **英式音标（IPA）** | 英语拼写和读音差距大，音标几乎必需；意大利语拼写和读音基本一一对应，词卡用"**大写标出重读音节**"（如 `buon-GIOR-no`）已能表达重音。用工具自动生成 IPA 在开口 / 闭口 e、o 上容易出错，**宁可不放，也不放可能教错的内容** |
| **英音 / 美音切换** | 意大利语没有这个维度 |
| **`build.py` 单文件打包** | 本项目有 3,324 个音频文件（约 32 MB），不适合塞进单个 HTML；直接双击 `index.html` 或发布 GitHub Pages 即可使用 |
| **课文"原声"** | 见第一节：本项目是合成语音 |

## 五、诚实说明（务必看）

1. **内容未经母语者审校。** 90 天的课文、对话、讲解、题目由 AI 辅助原创，做过自动校验（数据结构、Hunspell 拼写词典检查、重音位置逐词核对、语音回听抽查），但没有意大利语母语者或专业教师逐句审校。遇到不确定的用法，请对照词典和权威教材。
2. **语音是合成的。** 适合建立节奏、重音和双辅音的概念；口音细节、真实语流中的连读弱化，请多听真人材料来校准。程序里没有发音打分——录音只用于"和原音对比 + 自评"。
3. **彩色分析是规则标注，不是"标准答案"。** 全部 934 个课文句子都能给出分析（端到端测试逐句点开验证），并用单元测试固定了典型情况（冠词 vs 代词、名词 vs 动词同形、助动词 + 过去分词、情态动词 + 不定式……），但个别句子仍可能标错。拿不准时以课文讲解和词典为准。
4. **AI 老师可能出错**，而且需要你自己的 DeepSeek 账号和网络；不填 Key 不影响其他任何功能。
5. 仓库所有者尚未选择许可证（见 [CREDITS.md](../CREDITS.md)）。
