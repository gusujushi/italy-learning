# 课程数据格式

课程内容在 `data/island1.js … island9.js`，每个文件用 `Course.add([...])` 注册 10 天。元数据（阶段、岛屿）在 `data/meta.js`，发音实验室数据在 `data/pron.js`。

写完后运行 `node tools/validate.js` 检查结构；运行 `node tools/export_course.js && python3 tools/qa_italian.py …` 做意大利语拼写检查。

## 一天的结构

```js
{
  n: 12,                         // 第几天（1–90）
  it: 'Cosa mangi?',             // 意大利语标题
  zh: '你吃什么？',               // 中文标题
  test: true,                    // 仅每座岛的第 10 天：岛屿关卡（20 题）
  exam: true,                    // 仅第 30 / 60 / 90 天：阶段毕业考（30 题）
  goal: '目标1；目标2；目标3。',   // 用「；」分隔成要点
  scene: '对话发生的场景（中文）',

  dlg: `                          // 对话：每行「角色: 意大利语 | 中文」
    Marco: Ciao! | 嗨！
    Li Ming: Ciao! | 嗨！
  `,
  key: [0, 3],                   // 可选：加入复习卡的关键句（对话行序号，从 0 起）；省略则自动挑 2 句

  q: [ [题干, [选项…], 正确序号, 解析, 朗读文本?] ],   // 盲听后的理解题（≥2）

  vocab: `                        // 每行「意大利语 | 中文 | 重音提示」，重音提示用大写标出重读音节
    telefono | 电话 | te-LE-fo-no
  `,

  pron: {                        // 发音小练习（第 1–30 天必填，之后可选）
    t: '小标题',
    tips: ['要点（支持 **粗体**）'],
    drill: `词 | 中文`,           // 跟读词表
    twister: '绕口令 | 中文',    // 可选
  },

  gram: [                        // 知识点（语法 / 句型 / 用法），可多块
    { h: '标题', p: ['段落'], t: [['表头…'], ['行…']], eg: ['意大利语 | 中文'] },
  ],
  culture: '文化提示（**粗体** 支持）',

  text: { title: '短文标题', body: `意大利语 | 中文\n…\n\n（空行分段）` },  // 可选：阅读短文
  rq: [ [题干, [选项…], 正确序号, 解析] ],                                // 阅读理解题（有 text 时 ≥2）

  speak: `意大利语 | 中文提示`,       // 口语任务（≥3），每行一条
  wr: ['写作任务（中文）', '示范答案（意大利语，\\n 分行）', '示范答案的中文'],
  quiz: [ [题干, [选项…], 正确序号, 解析] ],   // 知识小测（≥3）
}
```

## 约定

- 行分隔符是 **` | `（竖线两边各一个空格）**。意大利语里不要出现这个组合。
- 对话里每行必须有角色标签（`Li Ming:`）。标签是 1–24 个字符，不含 `:`。
- 选项里不要出现两个完全相同的选项；正确序号从 0 开始。
- 意大利语一律用直撇号 `'`（`l'albergo`），程序会统一弯撇号。
- **不要提前使用还没教过的语法**。第 N 天出现的结构必须在之前的某一天学过（或在当天讲解）。
- 重复出现的词汇没关系：复习卡会按"意大利语 + 释义"自动去重，只在首次出现的那天生成。
- 每个意大利语文本都会被合成音频，所以**不要**在 `it` 一侧写箭头、括号注释、斜线并列等朗读不出来的符号。

## 自动生成的内容

练习不需要手写：程序从 `dlg` 和 `vocab` 自动生成听选、听写、排序、选择 / 键入填空、中译意、配对等题型（见 `js/exgen.js`）。每日小测 10 题，岛屿关卡 20 题，阶段毕业考 30 题。
