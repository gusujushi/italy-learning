# 意大利语能力岛 · 90 天课程设计

> 从零开始，90 天、9 座岛、听说读写五项能力同步推进。
> 本文是课程的"总设计图"：先讲设计思路，再给出 90 天逐日大纲，最后说明评估与质检方式。

---

## 1. 设计思路：我们从新概念英语学到了什么

"能力岛"在公开资料中没有统一定义。本课程把它理解为：**一条闯关式的岛屿学习路径——每座岛是一个能力阶段，每一天是岛上的一个站点，每个站点都要同时练到听、说、读、写**。这个理解与新概念英语类 App 的常见设计（逐句解析、课文听选、跟读录音、语法归纳、过关式学习）一致。

参考的 GitHub 项目与取舍见 [REFERENCES.md](REFERENCES.md)。提炼出的核心经验：

| 新概念英语程序的做法 | 本课程的对应设计 |
| --- | --- |
| 一课 = 一篇课文 + 单词 + 语法 + 练习，由浅入深 | 一天 = 一段对话/短文 + 词汇 + 知识点 + 练习，每天只解决 1 个交际任务 |
| 课文逐句"点读"，中英对照，可隐藏任一语言 | 每句可点读；中/意文可独立显示、隐藏或模糊 |
| 单句循环、整课循环、0.5–2.0 倍变速 | 单句循环、整段连播、0.7× / 0.85× / 1× 三档语速（不变调） |
| 跟读 → 录音 → 与原音对比 | 跟读步骤：听一句 → 录音 → 回放对比 → 自评（浏览器支持时附带语音识别匹配度） |
| 听写、课文听选、填空、翻译 | 全部保留，且由课文和词汇**自动生成**，保证练习与当天内容完全对应 |
| 连续学习天数、学习进度 | 连续天数、星级、五项能力雷达（听说读写＋知识）、徽章 |
| 先听后看（盲听）的训练顺序 | 每天先盲听回答问题，再看文本 |

和新概念英语不同的地方：

1. **发音前置。** 意大利语拼写几乎"所见即所读"，第 1–10 天集中打通发音体系，之后每天仍有 3 分钟"发音小练习"（`pron`）持续巩固。
2. **口语前置。** 英语新概念从语法出发；这里以"能马上用"的生活场景（咖啡吧、餐厅、问路、酒店）驱动，语法只讲当天要用的那一点。
3. **复习自动化。** 每个词和关键句都进入间隔复习（SRS），不用靠自觉。

## 2. 学习路径总览

```
阶段一 生存期（Day 1–30）   发音 + 日常/差旅口语      ≈ A1 入门
  ├ 第1岛 发音岛   Isola dei Suoni            Day  1–10
  ├ 第2岛 生活岛   Isola della Vita           Day 11–20
  └ 第3岛 旅行岛   Isola del Viaggio          Day 21–30

阶段二 成长期（Day 31–60）  语法骨架 + 日常交流        ≈ A1 完整 → A2 入门
  ├ 第4岛 日常岛   Isola della Giornata       Day 31–40
  ├ 第5岛 社交岛   Isola degli Amici          Day 41–50
  └ 第6岛 时间岛   Isola del Tempo            Day 51–60

阶段三 进阶期（Day 61–90）  叙事、观点、阅读写作、实战  ≈ A2（含少量 B1 入门内容）
  ├ 第7岛 记忆岛   Isola dei Ricordi          Day 61–70
  ├ 第8岛 观点岛   Isola delle Opinioni       Day 71–80
  └ 第9岛 毕业岛   Isola del Diploma          Day 81–90
```

**每座岛的第 10 天是"岛屿关卡"**（综合复习 + 测试，通关得岛屿徽章）；第 30、60、90 天是阶段毕业考。

**能力侧重**随阶段移动：

| 阶段 | 听 | 说 | 读 | 写 | 说明 |
| --- | :-: | :-: | :-: | :-: | --- |
| 一 | ★★★ | ★★★ | ★★ | ★ | 以听说为主；写作限于词、短句、听写、填空 |
| 二 | ★★★ | ★★★ | ★★★ | ★★ | 加入 80–100 词短文阅读；写 40–60 词的小短文 |
| 三 | ★★★ | ★★★ | ★★★ | ★★★ | 阅读通知/邮件/短故事；写 100–150 词；长段口语 |

## 3. 每日学习流程（约 50–60 分钟）

沿用"新概念"的**课文为中心**结构，拆成 6 个步骤（课程页顶部的步骤条），每一步都有明确的能力目标：

| 步骤 | 时长 | 做什么 | 主训练的能力 |
| --- | --- | --- | --- |
| ① 听 Ascolto | 8′ | **盲听**整段对话，回答 2–3 个理解题；再逐句听并对照文本 | 听 |
| ② 读 Lettura | 8′ | 中意对照精读：点读、循环、变速、点词看释义；词汇卡片与小练习 | 读 |
| ③ 学 Conoscenza | 10′ | 发音小练习 + 语法/句型 + 文化提示，附小测 | 知识 |
| ④ 说 Parlato | 10′ | 逐句跟读录音；角色扮演（你演 B）；看中文提示开口说 | 说 |
| ⑤ 写 Scrittura | 10′ | 听写、排序、填空、中译意；每天一个微写作任务（含示范） | 写 |
| ⑥ 测 Prova | 5′ | 10 题综合小测 → 1–3 星；词句自动加入复习 | 综合 |

另外有一个**课前热身（约 5′，可选）**：底部"复习"页签里的到期间隔复习卡（前几天的词句），地图首页会提示今天有多少张到期。

星级规则：正确率 ≥ 60% → ★；≥ 80% → ★★；≥ 95% → ★★★。**得到 ★ 即解锁下一天**，想再提高可随时重做。

## 4. 听说读写如何练

### 听 Ascolto
- 盲听 → 理解题 → 带文本精听（先听懂大意，再抠细节）。
- 听音选义、听写词/句、听力是非题。
- 阶段三加入"真实语速"的通知、语音留言、新闻简报（第 87 天）。

### 说 Parlato
- **影子跟读**：每句"听一句—说一句—录一句—回放比较"。
- **角色扮演**：程序读 A 的台词，你说 B 的台词（可换角色）。
- **看中文说意大利语**：每天 2–4 条场景任务。
- **补救策略**（第 88 天）：没听懂怎么办——"Può ripetere, per favore?""Come si dice … in italiano?"

### 读 Lettura
- 对话本身就是阅读材料；阶段二、三的大多数日子另附一篇 60–100 词的短文和阅读理解题（全程共 53 篇）。
- 第 36 天租房广告、第 67 天通知与新闻、第 85 天《木偶奇遇记》开篇（公有领域）。
- 点击任意词看当天词汇表中的释义。

### 写 Scrittura
- 阶段一：听写 → 填空 → 句子排序 → 中译意 → 一句话写作。
- 阶段二：便条、明信片、短信、日记（第 54、59 天）。
- 阶段三：正式邮件、故事复述、短文（第 68、69、86 天）。
- 每个写作任务都附**示范答案**与自查清单。

## 5. 发音训练体系

| 天数 | 重点 |
| --- | --- |
| 1 | 5 个纯元音；不要弱化、不要拖尾 |
| 2 | 不送气的 p/t/c（≈ 汉语拼音 b/d/g）与浊音 b/d/g；字母表；拼读名字 |
| 3 | c/g 的软硬（ce ci / ca co cu / che chi）；不发音的 h；sc |
| 4 | gn、gli、z、qu；**双辅音**（pala/palla）；大舌音 r |
| 5 | 重音规则（倒数第二音节）、重音符号、疑问语调 |
| 6–10 | 数字、国名、冠词连读、咖啡吧词汇的综合应用；绕口令 |
| 11 起 | 每天一个"发音小练习"：与当天词汇结合（双辅音、z、gli、重音例外…） |

发音实验室（App 内）包含：字母与发音对照表、最小对立词听辨（caro/carro）、重音练习、绕口令（scioglilingua）。

## 7. 复习与评估

- **间隔复习（SRS）**：莱特纳盒子法，6 个盒子，间隔 1 / 2 / 4 / 8 / 16 / 32 天。四档自评：不会（回到第 1 盒，今天再来一次）、模糊（留在原盒，间隔减半）、记得（升一盒）、很熟（升两盒）。每个词、每句关键对话是一张卡；同一个词在多天出现，只建一张卡（在它第一次出现的那天加入）。另有"错题重练"和"随机巩固"两种模式。
- **每日测验**：10 题，混合听选、听写、填空、排序、翻译。
- **岛屿关卡**：每岛第 10 天，题量 20，覆盖本岛全部内容，≥ 60% 通关得岛屿徽章。
- **阶段毕业考**：第 30/60/90 天，30 题，覆盖整个阶段的内容（听、读、写、知识）；口语与写作请认真完成当天的“说”“写”步骤并自评。
- **五项能力雷达**：听、说、读、写、知识，各按近期正确率滚动计算，直观看到短板。

## 8. 预期水平（实话实说）

按每天 50–60 分钟、认真完成所有步骤计：

- 第 30 天：能发音正确地读出意大利语单词；能在咖啡吧、餐厅、车站、酒店完成基本对话（大致相当于 A1 入门）。
- 第 60 天：A1 的语法和主题基本完整，能叙述简单的过去与计划。
- 第 90 天：约 A2 水平，含少量 B1 入门内容（条件式、虚拟式入门）。**这不等于 90 天后能流利交谈**；之后建议用真实材料大量输入，并找人对话。第 90 天提供后续路线（CELI / CILS / PLIDA）。

## 9. 内容原则与质检

1. **原创内容**：参考项目大多无开源许可证，因此课文、词汇释义、讲解均为原创，只借鉴设计思路。
2. **拼写质检**：全部意大利语文本用 LibreOffice 意大利语 Hunspell 词典逐词检查；未登录词人工复核（专有名词除外）。
3. **难度校验**：以 OpenSubtitles 词频表检查词汇覆盖，避免前期出现生僻词。
4. **结构校验**：脚本检查天数连续、对话格式、答案序号、必填字段。
5. **音频**：使用 Piper 的 `it_IT-paola-medium`（训练数据 CC0）合成；同时保留浏览器语音合成作为回退。合成语音不等于真人发音，**重音和语调请多听真人材料校正**。质检做过：重音位置与课程标注逐词核对（525 个词，一致率 99.4%，不一致的 2 个是课程标注错误，已更正）、双辅音时长对比、句子级语音识别回听抽查、响度与峰值检查。
